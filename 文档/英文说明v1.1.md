# Teardown for Codex · v1.1.0

[简体中文](../README.md) · [Live gallery](https://tuanziding.github.io/v8-interactive-simulator/gallery.html)

A reusable Codex skill with two ready-to-build, offline 3D examples: a V8 four-stroke engine and a procedural Sentinel-inspired robot. This release adds a deterministic scene generator that exports HTML, editable source and third-party notices.

## Install

Requires Node.js 20+, npm and Git. No Python or API key is needed for these HTML builds.

```sh
git clone https://github.com/TUANZIDING/teardown-codex.git "${CODEX_HOME:-$HOME/.codex}/skills/teardown-codex"
cd "${CODEX_HOME:-$HOME/.codex}/skills/teardown-codex"
npm run setup
```

Do not overwrite an existing installation. Start a new Codex chat and ask:

> Use $teardown-codex to generate both the V8 and Sentinel offline demos in a new project directory, including editable source.

## CLI

```sh
npm run generate -- all --out ./output-all
npm run generate -- v8 --out ./output-v8
npm run generate -- sentinel --out ./output-sentinel
npm test
```

The output must be a new directory. HTML files are self-contained; `source/` includes the builder and lockfile. To edit and rebuild, run `npm ci` in `source/`, then `node sims/build.mjs v8-live sentinel-live` (select only the examples you generated).

## Examples and scope

- [V8](https://tuanziding.github.io/v8-interactive-simulator/): transparent/section/solid display, cylinder tracking, RPM, valve timing and simplified pressure charts.
- [Sentinel](https://tuanziding.github.io/v8-interactive-simulator/sentinel.html): 400 links, 13 sensors, cruise translation and turns, articulated motion, isolation and exploded inspection.
- [Download finished demos](https://github.com/TUANZIDING/v8-interactive-simulator/releases/tag/v1.0.0).

The V8 uses an educational pressure model. The Sentinel is unofficial fan-made procedural geometry, without film assets or collision dynamics. A new machine still needs Agent-authored modelling; the CLI builds the supplied templates, not arbitrary CAD from text. Sentinel video export is not included.
